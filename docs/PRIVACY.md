# LangBlock privacy policy

_Last updated: 29 October 2026_

LangBlock does not collect, store, sell or share any personal data.

**What stays on your device**
- Your settings (languages to block and your options). If your browser syncs extension settings, they sync through your own browser account, which the developer cannot access.
- A cache of videos LangBlock has already checked: the video's id, the language codes found (from its captions, audio tracks, description and tags), whether YouTube held the details back, and when it was checked. It never leaves your device, expires automatically, and can be cleared from LangBlock's settings page.

**Network requests**
LangBlock makes no requests to the developer or any third party. Its only requests go to YouTube (www.youtube.com or m.youtube.com): it loads a video's YouTube page to read the language information YouTube publishes for that video. These requests come from your browser, just like opening YouTube yourself. LangBlock does not play videos.

**No analytics, no ads, no tracking.** LangBlock contains no analytics, advertising or tracking code, and loads no code from the internet.

**Ownership and updates**
- LangBlock will never be sold or handed over to anyone who would add tracking, advertising, data collection or other harmful code. The developer does not accept payment to add any of these, or to put anyone else's code into LangBlock.
- If LangBlock ever changes hands, it will only be to someone who agrees to keep this policy, and it will be announced on the GitHub page and the store listings before it happens, so you can decide whether to keep using it.
- Any change to this policy will be announced on GitHub before an update that relies on it, and the date at the top will change.
- Every version's source code is public on GitHub, and every update is reviewed by the Chrome Web Store and Firefox Add-ons before it reaches you.

**Donations**
The optional "Support LangBlock" link opens the donation page in a new tab. LangBlock sends nothing to that site; anything you do there is covered by that site's own privacy policy.
